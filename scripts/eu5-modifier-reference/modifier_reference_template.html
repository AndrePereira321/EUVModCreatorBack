EU5 Country Modifiers

Every modifier a country can use in Europa Universalis V, read from your installed game and DLC files, with the values the game itself uses.
How to read this
  • Click a script_key to copy it. Put it in a static modifier like tax_income_efficiency = 0.05.
  • Min / Most common / Max are the fixed values the base game and DLCs write for that modifier. The source of each one is shown below it. Named script values such as small_permanent_target_satisfaction, @variables and @[math] are resolved to numbers. Expand "All values" to see which name was used.
  • The big number is what you type in script. The small grey one is how the game displays it (for percent modifiers, 0.05 = +5%).
  • Green and red follow the game's own tooltip colours: green means the value helps you.
  • Scaled at runtime values are multiplied by something in game, such as estate power, a societal value slider, population, doom or bureaucracy upkeep. They are left out of min/max because the written number is not the final effect.
  • Computed from game state values come from a formula (a script value that depends on the country) and have no single number.
  • Base value is what every country gets automatically (country_base_values), so it's not counted as a bonus.
  • Unit modifiers in a country modifier apply to all of that country's units. Location, character and religion modifiers are not listed: they don't work in a country modifier.
  • Static modifiers applied by the engine (difficulty, ruler skills, inflation, years since start...) may be scaled by the engine too. Check the source before copying an extreme value.
